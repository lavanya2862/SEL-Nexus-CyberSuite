Fix Centre

How it works

1 · PlanEvery run turns Defender's list into fixes: update, remove (end-of-life) or replace, from the fixed list config/fix_catalog.csv. The AI never chooses commands.
2 · You approveTick fixes and press Approve. Nothing runs without this.
3 · UC1 fixes"Run approved fixes" sends a script to the lab VM through Azure Run Command or Defender Live Response. It closes the app, then updates or removes it.
4 · Defender confirmsDefender notices the change within 2–6 hours. The next UC1 run marks the fix Verified ✓.
