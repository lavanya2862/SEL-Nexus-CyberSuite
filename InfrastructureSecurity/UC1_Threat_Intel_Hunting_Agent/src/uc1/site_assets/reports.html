AI spot-check

How you measure the AI's accuracy yourself: open the workbook, type Y (right) or N (wrong) in the 4 check columns for each of the 20 AI answers, save, then run this in PowerShell in the UC1 folder:

.\.venv\Scripts\python.exe -m uc1 spotcheck

The result appears in the "AI accuracy" tile on the Command Centre. No workbook yet, or want a new sample of 20? Run .\.venv\Scripts\python.exe -m uc1 spotcheck (without --score).
