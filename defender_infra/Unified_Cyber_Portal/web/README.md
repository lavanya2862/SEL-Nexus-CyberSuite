# SEL Nexus CyberSuite web app

React + TypeScript + Vite front end of the Unified Cyber Portal. See [../README.md](../README.md) for setup.

```powershell
npm ci
npm run dev      # hot reload; /api calls go to the portal on http://127.0.0.1:8800
npm run build    # builds dist/, served by `python -m portal serve`
```
